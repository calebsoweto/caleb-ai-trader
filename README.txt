CALEB AI TRADER — WEB APP STARTER

This is a static, mobile-friendly web app prototype for iPhone and Android.

Included: Home, Markets, Bot, Account screens; $50 demo balance; virtual top-up; sample market rows; locally logged demo Buy/Sell actions; risk-profile selector; broker connection placeholders.

IMPORTANT: This is not a live trading product. Market prices are placeholders. Demo orders are only logged in the browser and are not sent to a broker. The auto-mode switch is a visual demo only. No real account login, API integration, deposits, withdrawals, or live execution exists. A production version requires secure backend services, official broker authorization, risk controls and testing.

DEPLOY: Upload index.html, manifest.webmanifest and this README to a GitHub repository. In Vercel, import that repository and deploy it as a static site. No build command is needed; output directory is the repository root.
